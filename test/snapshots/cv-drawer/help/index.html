# CV Drawer Help

CV Drawer is a free Mac app for creating CVs and exporting them to PDF. It works on macOS 13 Ventura or later, on Macs with Apple silicon and with Intel processors.

## How do I install CV Drawer?

- Mac App Store: install it like any other app from the App Store. - Downloaded from GitHub: open the downloaded CV-Drawer-<version>.dmg file, drag CV Drawer to the Applications folder, then close the window and eject the "CV Drawer" disk in Finder (the ⏏ button next to its name). The first time, open CV Drawer from the Applications folder or from Launchpad. The .dmg version is signed and checked by Apple (notarized), so macOS opens it without warnings; it may only ask whether to open an app downloaded from the internet. Click Open.

## Where is my data?

Your CVs, the clause library and your settings are saved automatically on this Mac, in the app's folder: ~/Library/Containers/com.michalstaniecko.mojecv/Data/Library/Application Support/Moje CV The folder keeps the app's earlier name, "Moje CV". The Mac App Store version and the version downloaded from GitHub share this folder, so on one Mac you always see the same CV library. Nothing is sent anywhere: see the Privacy Policy. Removing the app from the Applications folder does not delete your data.

## I used an older version. Where are my CVs?

The first time you open the new version, macOS moves the CVs from the older version (named "Moje CV" or "CV Press") into the folder above. You don't need to do anything. CV Drawer appears in the Applications folder next to the older app; once CV Drawer shows your CVs, move the older app to the Trash, because it no longer sees them. If a CV is missing, open the older version, export the CV to a file and import it in CV Drawer, as described below.

## How do I move a CV to another Mac or keep a backup?

1. In the CV library, click Export to file next to the CV (or open the CV and choose File → Export JSON…). Save the .json file somewhere safe, for example on a USB drive or in iCloud Drive. 2. On the other Mac, open CV Drawer and click Import from file in the CV library (or choose File → Import…). Pick the .json file. The file contains the whole CV, including the photo, so treat it like any other document with your personal data.

## Can I edit my CV in Word or another editor?

Yes. Open the CV and choose File → Export to DOCX… (or click Export to DOCX in the editor). You get a .docx file that you can open in Word, Pages, LibreOffice or Google Docs, for example to add something the app's sections don't cover. The DOCX file uses a simplified layout for editing, the same for every template: it keeps the content, the accent colour, the font and the CV language. The PDF matches the preview, so export to PDF when you want the CV to look exactly like in the app. - The photo goes into the file only if it's a JPEG or PNG image. The photo in the sample CV isn't, so a DOCX of the sample CV has no photo. - The DOCX file is a one-way copy: CV Drawer doesn't read it back, so changes you make in the editor stay only in that file.

## How do I update the app?

- Mac App Store: the App Store delivers updates like for any other app. - Downloaded from GitHub (.dmg): CV Drawer tells you when a new version is available, and you can check yourself with Help → Check for Updates…. The app never downloads or installs anything by itself. Click Download, open the new .dmg file and drag CV Drawer to the Applications folder, choosing Replace. Your CVs stay where they are. All versions are on the releases page ↗.

## Something doesn't work or I have an idea

Report a problem or suggest a feature ↗ on GitHub (you can also use Help → Report a Problem… in the app). Please give the app version from CV Drawer → About CV Drawer, for example "1.0.0 (12)", and your macOS version. Reports on GitHub are public. Please don't attach a CV with your real personal data: if a CV is needed to show the problem, use a sample CV or replace the data with made-up text.
